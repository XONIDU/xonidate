# Somos XONIDU

# Requisitos mínimos
Asegúrate de tener instalado Python 3 en tu sistema. Luego, instala las dependencias necesarias según tu sistema operativo:

---

## Instalación en **Arch Linux**
```bash
sudo pacman -S python-pip python-pillow
pip install flask fpdf qrcode[pil] --break-system-packages
```

## Instalación en **Ubuntu y derivados**
```bash
sudo apt update
sudo apt install python3 python3-pip python3-pil -y
pip3 install flask fpdf qrcode[pil] --break-system-packages
```

## Instalación en **Windows**
```bash
pip install flask fpdf qrcode[pil] pillow
```

## Instalación en **macOS**
(Asegúrate de tener Homebrew instalado: https://brew.sh/)
```bash
brew install python3
pip3 install flask fpdf qrcode[pil] pillow
```

---

# Ejecución de la aplicación:

Para ejecutar el programa utiliza el siguiente comando:
```bash
python start.py
``` 

# Ejecución de la aplicación Visual:

Para ejecutar el programa y acceder a la aplicación web, utiliza el siguiente comando:
```bash
python page.py
```

La aplicación estará disponible en:
- Local: http://127.0.0.1:5000
- Red local: http://TU-IP-LOCAL:5000

Se mostrará un código QR en la terminal para acceso rápido desde dispositivos móviles.
